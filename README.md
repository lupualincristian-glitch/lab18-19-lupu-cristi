## Reguli

- Repozitoriul tău se creează **o singură dată**, din acest șablon (**Use this template**), cu numele `lab18-19-<nume-prenume>`, **Private**, în organizația `AAW2341`.
- Numele repozitoriului contează: din el se calculează **varianta ta de date**. O vezi în subsolul fiecărei pagini.
- Ambele ramuri se creează din `main`. La laboratorul 19 alegi `main` la **Based on**.
- După fiecare sarcină: **Commit All and Push**, cu mesajul din fișă (`S1: …`, `S2: …`).
- Capturile de ecran merg în `Raport/capturi/`, cu numele din tabelul de testare.
- Predarea: Pull Request din ramura laboratorului în `main`, cu titlul `Lab 18` sau `Lab 19`. **Nu apăsa Merge.**
- La Pull Request rulează **verificarea automată**. Rezultatul apare în josul Pull Request-ului (✅ sau ❌); **Details** arată ce a trecut și ce nu.
- Nu modifica folderul `.github` și nici fișierele `Models/Varianta.cs` și `Models/Baza.cs`.

Fișele de laborator sunt în ClassRoom.
